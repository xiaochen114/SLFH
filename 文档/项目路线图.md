## 📌 Phase 1 — RobotBase + 中央大脑框架（现在就能做 💻）

**不需要机房，纯代码开发。**

### 1.1 抽象接口层

```
E:\zy\机器人\__init__.py
E:\zy\机器人\robot_base.py        ← RobotBase 抽象基类
E:\zy\机器人\机器人模拟器.py      ← 模拟机器人用于测试
```

- [ ] 定义 `RobotBase`（ABC）
- [ ] 定义 `RobotOrder` / `RobotStatus` / `OrderResult`
- [ ] 写模拟机器人：模拟心跳、状态上报、指令响应
- [ ] 写单元测试

### 1.2 机器狗适配

```
E:\zy\机器人\机器狗_绝影.py       ← 继承 RobotBase，封装原 DogController
```

- [ ] `机器狗_绝影` 继承 `RobotBase`
- [ ] `connect()` → 调用原 `DogController.connect()`
- [ ] `execute_order()` → 将标准 order 转为 UDP 指令
- [ ] `get_status()` → 返回标准 RobotStatus
- [ ] `on_communication_lost()` → 进入边缘自主

### 1.3 中央大脑框架

```
E:\zy\中央大脑\__init__.py
E:\zy\中央大脑\brain_registry.py   ← 设备注册中心
E:\zy\中央大脑\brain_comm.py      ← 通信管理层
E:\zy\中央大脑\brain_web.py       ← Web 面板（改造已有）
E:\zy\中央大脑\brain_llm.py       ← LLM 调度引擎（框架）
E:\zy\中央大脑\brain_scheduler.py ← 任务规划器
E:\zy\中央大脑\brain_ops_agent.py ← 运维 Agent
E:\zy\中央大脑\main.py            ← 中央大脑主入口
```

- [ ] `brain_registry`：注册/注销/发现/心跳检测
- [ ] `brain_comm`：消息路由、缓存、重连补发
- [ ] `brain_web`：基于已有 web_dashboard.html 改造
- [ ] `brain_llm`：API 调用封装（DeepSeek 占位）
- [ ] `brain_scheduler`：任务分解与下发
- [ ] `brain_ops_agent`：SSH 远程诊断框架
- [ ] `main`：启动所有模块

### 1.4 联调测试

- [ ] 模拟器连中央大脑：注册 → 上报 → 下发指令 → 响应
- [ ] Web 面板实时显示模拟机器人状态
- [ ] 所有代码 push GitHub
