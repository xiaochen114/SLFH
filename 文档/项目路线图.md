## ✅ Phase 1 — RobotBase + 中央大脑框架（已完成）

### 1.1 抽象接口层

```
src/机器人/robot_base.py        ← RobotBase 抽象基类
src/机器人/机器人模拟器.py      ← 模拟机器人
src/机器人/机器狗_绝影.py      ← 绝影适配（继承 RobotBase）
src/机器人/机器狗控制.py       ← 绝影 UDP 通讯封装
src/机器人/感知主机控制.py     ← SSH 操控感知主机 ROS2
```

- [x] `RobotBase`（ABC）+ `RobotOrder` / `RobotStatus` / `OrderResult`
- [x] 模拟机器人：心跳、状态上报、指令响应
- [x] `机器狗_绝影` 继承 RobotBase
- [x] **系统 ID 机制**：注册时分配 `品牌-时间戳` 唯一 ID
- [x] **指令标签路由**：指令带 robot_id，按标签下发

### 1.2 中央大脑框架

```
src/中央大脑/main.py            ← 主入口
src/中央大脑/brain_registry.py  ← 设备注册中心（系统ID）
src/中央大脑/brain_comm.py     ← 通信管理（离线缓存/重连补发）
src/中央大脑/brain_llm.py      ← LLM 调度（API + 降级 + 重连）
src/中央大脑/brain_scheduler.py← 任务规划器
src/中央大脑/brain_web.py      ← Web API v1 + SSE
```

- [x] 注册/注销/心跳检测
- [x] 消息路由、离线缓存、重连补发
- [x] LLM 调度：DeepSeek API + 规则降级 + 后台重连
- [x] 调度决策**异步化**（后台线程，不阻塞主循环）

### 1.3 升级模块（超出原计划）

```
src/中央大脑/事件总线.py     ← 发布/订阅 + SSE 推送
src/中央大脑/数据库.py      ← SQLite 持久化（11 张表）
src/中央大脑/监控告警.py     ← 异常检测（低电量/断连/健康）
src/中央大脑/检测服务.py     ← 多路视频流 YOLO 检测
src/中央大脑/运维自愈.py     ← 自愈框架（诊断器/闸门/LLM）
src/中央大脑/记忆管理器.py   ← LLM 对话记忆（可升级RAG）
src/中央大脑/自主巡逻.py     ← 巡逻调度（点管理/导航）
src/中央大脑/诊断脚本_*.py  ← 绝影/感知主机诊断器
```

- [x] 事件库 + 标签 + 紧急度（0普通/1紧急/2特急）
- [x] 高危三件套：急停 + 报火警 + 记录（不依赖 LLM）
- [x] 自愈系统：诊断器 / 两级闸门 / LLM 增强
- [x] 告警双通道：SSE 即时 + 数据库持久 + 分级清理
- [x] 指挥台：LLM 状态卡 / 调度流水 / 对话 / 待确认 / 干预
