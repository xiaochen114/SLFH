# 运维自愈系统 实现计划

**目标：** 实现规则诊断优先、LLM增强的机器人自愈框架，低危操作自动执行，高危操作人工确认

**架构：** 诊断器注册表（通用框架）+ 高危闸门 + 事件库打标签 + Web确认API。复用现有 LLM调度引擎（含降级重连）

**技术栈：** Python, paramiko(SSH), 现有事件总线/数据库/brain_llm

**硬约束：** 内网LLM 2026-10-30到期，自愈核心必须能完全脱离LLM运行

  ```python
  def 执行SSH(self, host, user, pwd, cmd):
      """SSH执行命令，返回输出"""
      import paramiko
      ssh = paramiko.SSHClient()
      ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
      ssh.connect(host, username=user, password=pwd, timeout=5)
      _, stdout, stderr = ssh.exec_command(cmd, timeout=10)
      out = stdout.read().decode()
      ssh.close()
      return out
  ```
